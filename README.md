# 中药调剂称量防错

该项目记录处方药味、药斗身份、电子秤事件和双人复核。核心原则是**逐味负责**：
每味药单独扫码核验、单独去皮称量、单独双人复核，任一袋总重相符都不能替代
逐味校验。

基础结构位于 `dispensing/contracts.py`，领域服务位于 `dispensing/service.py`，
`dispensing/replay.py` 依据 `fixtures/weighing_session.json` 还原一次脱敏的
错斗（制南星/胆南星名称相近）、校准失效、换秤与回退取药全过程。

## 防错规则

- 调剂员领取药味后逐味扫描药斗，药斗身份必须与处方快照一致；
- 秤台读数只能归入当前药味与已核验药斗；去皮、加减、回退逐笔保留事件顺序；
- 换秤后旧去皮值作废，必须在新秤重新去皮；旧秤迟到/重发读数一律拒收；
- 校准失效、药斗停用、确认时超出剂量容差、身份不符 → **立即锁定该味**，
  当次尝试不可恢复，只能另起一次尝试，锁定原因跨尝试、跨交班保留；
- 复核员不得复核自己的称量；未复核不能封袋；已封袋只能进入拆包复核；
- 处方变更使所有未封袋任务立即失效，已封袋不受影响；
- 扫码（scan_id）、秤台事件（event_id）、复核（review_id）全部幂等，
  重放不产生重复效果，内容不一致的重放被拒绝；
- 全部药味逐味合格并封袋后，才生成唯一一份《中药调剂合格单》，逐味列出
  目标量、实际量、设备校准状态、双人责任与该味的锁定历史。

## 运行

```bash
python -m compileall dispensing          # 语法检查
python -m dispensing.replay              # 回放 fixture，输出合格调剂单
python -m pytest tests/                  # 规则测试（30 项）
```
