# 中药调剂称量防错

该项目记录处方药味、药斗身份、电子秤事件和双人复核。读数、去皮及回退均保留发生顺序，设备校准状态随称量记录保存。

基础结构位于 `dispensing/contracts.py`，`fixtures/weighing_session.json` 还原一次脱敏的换秤与错斗过程。项目面向 Python 3.11，可使用 `python -m compileall dispensing` 检查语法。

## 组成

- `dispensing/contracts.py` — 处方药味、秤台事件、复核记录的基础类型（不改）
- `dispensing/models.py` — 任务/药味状态机、锁定记录、合格调剂单
- `dispensing/service.py` — 防错服务：扫码核身、秤台事件归口、锁定、换秤、双人复核、处方变更、交班报告
- `demo.py` — 按 fixture 还原错斗 → 校准失效 → 换秤 → 回退 → 复核全过程
- `tests/test_service.py` — 逐规则单元测试

## 防错规则

- 调剂员领取任务后逐味扫描药斗，与处方快照不符或药斗停用立即锁定该味
- 秤台读数只归入当前药味；去皮、加减、回退全部按顺序留痕
- 校准失效、超出剂量容差立即锁定该味，失效读数不计入净重
- 换秤后旧去皮值作废，新秤必须重新去皮；旧秤事件一律拒收
- 复核员不得复核自己的称量；封袋须全部药味合格
- 处方变更使未包装任务作废，已封袋任务只能进入拆包复核
- 扫码与秤台事件按标识幂等，重发返回首次结果
- 锁定记录永久保留，交班后仍可查看锁定原因
- 复核通过后开具合格调剂单，每个任务仅一份，逐味显示目标量、实际量、设备状态及双人责任

## 运行

```bash
python3 demo.py                              # 端到端演示
python3 -m unittest discover -s tests -v     # 单元测试
```
